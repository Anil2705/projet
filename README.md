# Portfolio professionnel — Anil Abasse

Ce dépôt contient le portfolio statique d'Anil Abasse dans [`docs/index.html`](docs/index.html).

## Publication sur GitHub Pages

Dans **Settings → Pages** :
1. Choisir **Deploy from a branch**.
2. Sélectionner la branche **main** et le dossier **/docs**.
3. Cliquer sur **Save**.

L'adresse publique, après activation et déploiement, sera : https://anil2705.github.io/projet/

Le portfolio est un fichier HTML autonome avec les styles, les interactions et le CV intégrés. Aucune source ni secret provenant des dépôts privés n'a été copié.

Le CV est provisoire : l'employeur de l'expérience en aide comptable n'a pas encore été précisé.
